# Bilibili Web Focus

一个面向 Microsoft Edge 的 Manifest V3 浏览器扩展，通过隐藏 B 站首页推荐、导航入口、视频页推荐与评论区等内容，减少浏览过程中的干扰。

扩展完全在本地运行，不需要构建，也不会上传浏览记录、搜索内容或账号信息。详细信息见 [隐私政策](bilibili_web_focus/PRIVACY.md)。

## 功能

- **首页专注模式**：隐藏首页横幅、频道栏和推荐内容，只保留顶部搜索框。
- **精简顶栏**：隐藏左右导航与用户入口，保留搜索区域。
- **清理搜索框**：不显示搜索框占位文字；搜索框为空时隐藏热搜面板，开始输入后恢复搜索补全。
- **搜索结果页豁免**：搜索页的正文搜索框和搜索结果保持可用。
- **视频页精简**：隐藏侧边广告、普通推荐、标签栏、投稿活动栏和评论区，保留播放器及系列选集。
- **全局开关**：在扩展弹窗中随时启用或暂停专注模式。
- **动态页面支持**：监听 B 站单页应用的路由与 DOM 变化，页面内跳转后自动重新应用规则。

## 安装

1. 下载或克隆本仓库。
2. 在 Edge 地址栏打开 `edge://extensions/`。
3. 开启页面中的“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择仓库中的 `bilibili_web_focus/` 目录。
5. 将扩展固定到工具栏，点击图标即可控制开关。

扩展目录为：

```text
bilibili_web_focus/
├─ manifest.json
├─ ext/
│  ├─ content/
│  └─ popup/
├─ LICENSE
└─ PRIVACY.md
```

仓库根目录是项目工作区，内层 `bilibili_web_focus/` 才是需要加载的扩展目录。

## 使用

安装后默认启用。点击工具栏中的扩展图标，可以查看当前状态并切换总开关。设置通过 `chrome.storage.sync` 保存，并会同步到已打开的 B 站页面。

关闭开关后，扩展会立即停止应用隐藏规则。由于部分规则会修改页面节点属性，若页面显示异常，刷新当前标签页即可恢复 B 站的默认页面。

## 运行范围

内容脚本仅匹配以下地址：

- `https://bilibili.com/*`
- `https://*.bilibili.com/*`

扩展会区分首页、视频页、搜索页和其他页面，并只对相应的页面区域应用样式规则。

## 权限与隐私

- `storage`：保存并同步总开关状态。
- 站点访问权限：在 B 站页面中注入脚本和样式，以实现内容隐藏及路由监听。

扩展不注入远程代码，不读取 Cookie，不收集分析数据，也不向外部服务器发送信息。完整说明见 [PRIVACY.md](bilibili_web_focus/PRIVACY.md)。

## 兼容性与限制

- 主要面向最新版 Microsoft Edge，使用 Chromium Manifest V3 的浏览器通常也可以加载。
- 页面规则依赖 B 站当前的 DOM 结构和样式类名。B 站改版后，个别规则可能失效，需要更新选择器。
- 扩展只调整页面的显示状态，不修改账号、历史记录、播放进度或 B 站服务器上的数据。
- 本项目与哔哩哔哩官方无关联，不代表或代替 B 站的服务与政策。

## 开发

项目使用原生 JavaScript、HTML 和 CSS，不需要安装依赖或执行构建：

```text
bilibili_web_focus/
├─ manifest.json          # 扩展清单
└─ ext/
   ├─ content/
   │  ├─ core.css         # 页面隐藏规则
   │  └─ index.js         # 页面识别、路由监听与开关同步
   └─ popup/
      ├─ popup.html       # 扩展弹窗
      ├─ popup.css
      └─ popup.js
```

修改文件后，在 `edge://extensions/` 中点击扩展卡片上的“重新加载”，再刷新 B 站页面即可验证。调整页面选择器时，建议同时检查首页、视频页、搜索页及页面内跳转场景。
